How to play

  1. Create a new game to get a 6-character room code, or join with a code someone shared with you.
  2. Once both players have joined, X always moves first — tap any empty square on your turn.
  3. Get three of your marks in a row — across, down, or diagonal — to win the round.
  4. Hit Play Again to start the next round in the same room — the score at the top keeps counting for as long as you're both here.
  5. Use Copy link to send your opponent a link that fills in the room code for them automatically.
